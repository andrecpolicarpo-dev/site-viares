## Formulário
O formulário usa inicialmente:
`https://formsubmit.co/contato@viares.eng.br`

Na primeira submissão, o FormSubmit enviará uma confirmação para o e-mail. Confirme uma vez.

O formulário captura UTM Source, Medium, Campaign, Term, Content, GCLID e URL de origem.

Para operação em escala, substitua o FormSubmit por CRM/backend próprio.

## Publicação
### cPanel
Envie todo o conteúdo desta pasta para `public_html`.

### GitHub Pages
1. Suba os arquivos em um repositório.
2. Ative Pages.
3. O arquivo `CNAME` está configurado para `www.viares.eng.br`.
4. Configure o DNS conforme o GitHub solicitar.

## SEO / Google
Após publicar:
1. Verifique o domínio no Google Search Console.
2. Envie `https://www.viares.eng.br/sitemap.xml`.
3. Solicite indexação das páginas principais.
4. Complete e verifique o Perfil da Empresa no Google.
5. Mantenha nome, telefone, site e área de atendimento consistentes.
6. Cadastre no Perfil da Empresa os mesmos serviços usados no site.
7. Publique fotos reais e cases autorizados.
8. Peça avaliações reais de clientes.
